## 🧑‍💻 About Me

I'm a **Senior QA Engineer** specialising in **DeFi protocol testing**, **smart contract quality**, and **end‑to‑end automation** for Web3 products. I’ve worked across trading and DeFi systems, with experience in lending, vaults, AMMs, liquidation flows, and oracle edge cases.

I care about:

- **DeFi Protocol Testing** — lending lifecycle, liquidation mechanics, risk and health factors  
- **Smart Contract Quality** — invariant testing, fuzzing, static analysis, regression safety nets  
- **QA Automation** — full‑stack testing across contracts, backend, and frontend with CI/CD  
- **Tooling** — Solidity, Foundry, Echidna, TypeScript, Playwright, GitHub Actions  

📍 Based in **Hong Kong**
